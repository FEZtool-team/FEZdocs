# FEZdocs

FEZdocs is the centralized documentation platform for the FEZtool ecosystem — a growing collection of remote sensing, geospatial, image processing, and scientific Python tools developed by FEZteam.

Built to be practical, developer-friendly, and easy to navigate, FEZdocs combines technical documentation, examples, concepts, experiments, and development notes in one place.

---

## Overview

This repository contains the official documentation for FEZtool libraries and related projects maintained by FEZteam.

The goal is simple:

* Make complex workflows easier to understand
* Document tools as they evolve
* Provide real-world examples instead of vague theory
* Create a reliable reference for contributors and users

Whether you're processing satellite imagery, experimenting with spectral indices, building geospatial workflows, or exploring image analysis techniques, FEZdocs aims to serve as the main knowledge hub for the ecosystem.

---

## Contents

### Library Documentation

Detailed guides and references for FEZtool libraries, APIs, modules, and utilities.

### Remote Sensing Concepts

Explanations of remote sensing fundamentals, spectral analysis, image processing methods, and geospatial workflows.

### Experiments & Research

Prototype implementations, experimental features, algorithm tests, and exploratory ideas.

### 🛠 Developer Notes

Architecture decisions, project structure, packaging workflows, testing strategies, and contributor resources.
